# Dados brutos

O arquivo bruto **não está versionado** neste repositório. Baixe-o na fonte oficial:

- **Fonte:** Portal de Dados Abertos do Governo do Distrito Federal
- **Link:** https://www.dados.df.gov.br/pt/dataset#/infracoes-transito
- **Conjunto:** Autos de infração de trânsito em vias do DF, consolidação de junho/2026

## Como usar

1. Baixe o CSV de junho/2026 no link acima.
2. Salve-o nesta pasta (`data/`), mantendo o nome original do arquivo.
3. Confira que o caminho definido na variável `ARQUIVO` do notebook aponta para ele.

## Formato esperado

- Separador: `;`
- Codificação: UTF-8
- 10 colunas, cerca de 81 mil linhas
